# Experiment 8 observations and conclusion

Delegation changes voting power, not token ownership. The proposal threshold checks current delegated votes. The historical snapshot isolates voter weight from transfers and delegation changes made afterward. With the experiment's fixed 1,000 CDT supply, 4% quorum is 40 CDT, equal to the configured minimum. A proposal passes only when it meets quorum and For strictly exceeds Against; no turnout is defeated after the deadline.

All nine experiment cases passed against the shared DAO infrastructure. Startup proposals carry an existing startup ID and request amount, while governance outcome remains separate from funding execution. This is an academic demonstration, not audited production governance.
